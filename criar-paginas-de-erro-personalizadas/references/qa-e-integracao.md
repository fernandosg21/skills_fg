# QA e integração — páginas de erro

## Identidade

- [ ] A logo é o arquivo oficial.
- [ ] A proporção da logo foi preservada.
- [ ] A paleta vem do projeto.
- [ ] Tipografia e formas combinam com a interface.
- [ ] Não há elementos herdados de outra marca.
- [ ] A ilustração usa uma metáfora coerente com o erro.

## Conteúdo

- [ ] Código em HTML.
- [ ] Título em HTML.
- [ ] Explicação em HTML.
- [ ] Botão em HTML.
- [ ] Logo fora da ilustração.
- [ ] Arte sem texto funcional.
- [ ] Mensagem sem culpa ou jargão desnecessário.
- [ ] Ação principal leva a um destino real.
- [ ] Nenhum dado interno sensível é exibido.

## Layout

- [ ] Verificado em desktop.
- [ ] Verificado em celular.
- [ ] Verificado em 320 px.
- [ ] Verificado com zoom de 200%.
- [ ] Sem scroll horizontal.
- [ ] Logo não sobrepõe o código.
- [ ] Título não invade a arte.
- [ ] Área de conteúdo continua legível sem a imagem.
- [ ] Botão aparece sem rolagem excessiva.
- [ ] Safe areas respeitadas.

## Acessibilidade

- [ ] Documento com `lang`.
- [ ] `meta viewport`.
- [ ] Um `<main>`.
- [ ] Um `<h1>`.
- [ ] Foco visível.
- [ ] Navegação por teclado.
- [ ] Logo com alt significativo.
- [ ] Artes decorativas com `alt=""`.
- [ ] Contraste adequado.
- [ ] Informação não depende apenas de cor.
- [ ] `prefers-reduced-motion` respeitado.
- [ ] Página compreensível sem CSS ou imagem.

## Técnica

- [ ] Status HTTP real.
- [ ] `noindex, nofollow`.
- [ ] CSS separado.
- [ ] Conteúdo essencial funciona sem JS.
- [ ] Assets locais ou com fallback.
- [ ] Caminhos absolutos/relativos testados.
- [ ] Página 500 não depende do banco.
- [ ] Página 503 não depende da sessão.
- [ ] Sem CDN indispensável.
- [ ] Sem erros no console.
- [ ] Sem requests 404 de assets.
- [ ] HTML válido.
- [ ] Manifest válido.

## Desempenho

- [ ] SVG é vetor real.
- [ ] Raster exportado como PNG/WebP/AVIF.
- [ ] Imagens otimizadas.
- [ ] Sem biblioteca pesada exclusiva para o erro.
- [ ] Fontes possuem fallback.
- [ ] Página crítica carrega rapidamente.

## Entrega

- [ ] Prévia usa o HTML/CSS final.
- [ ] Contact sheet atualizado.
- [ ] README explica integração.
- [ ] Lista de códigos documentada.
- [ ] ZIP validado.
- [ ] Limitações declaradas.
